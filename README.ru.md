# The Simpsons: Hit & Run (SRR2) — открытая пересборка

В этом репозитории хранится исходный код игры _The Simpsons: Hit & Run_ с рядом
улучшений: сборки C++20 и x64, vcpkg для удобного управления сторонними
библиотеками, UWP-сборки, а также новый слой **сетевого мультиплеера** на базе
ENet.

> Что изменилось по сравнению с оригиналом — см. **[Изменения относительно оригинала](#изменения-относительно-оригинала)**.
> Подробное описание сетевой архитектуры — в **[SPEC.md](./SPEC.md)**.

## Изменения относительно оригинала

Этот форк добавляет к базовому коду многослойный сетевой мультиплеер с нуля и
ряд улучшений качества жизни. Полное техническое описание — в
[SPEC.md](./SPEC.md); кратко:

### Мультиплеер (новое)

- **Сетевой стек на ENet** (`src/game/network/`): надёжный клиент-серверный слой
  с **серверно-авторитетной моделью** — сервер допускает игроков, выдаёт
  `clientId`, проверяет движение и ретранслирует состояния. Без предположения
  о peer-to-peer.
- **Жизненный цикл хоста / подключения**: консольные команды (`host`, `join`,
  `match`) и автозапуск из командной строки (`HOSTPORT=`, `JOINIP=`, `HOSTPASS=`,
  `HOSTSLOTS=`, `JOINPASS=`).
- **Отображение удалённых игроков**: сетевые персонажи и машины-«призраки»
  водителей плавно спавнятся и интерполируются в мире
  (`RemotePlayerWorldView`, `RemoteVehicleWorldView`).
- **Список игроков и присутствие**: сервер рассылает авторитетный список
  сущностей; клиенты видят уведомления о подключении/отключении.
- **Heartbeat и контроль жизни**: PING/PONG даёт замер задержки (RTT) и
  позволяет серверу отваливать «молчащих» клиентов, а не держать пустые слоты.
- **Серверные Lua-моды**: скрипты могут перехватывать решения о допуске,
  проверке и выходе игрока (`ServerModManager`).
- **Выделенный сервер**: headless-консольный сервер (`mp_standalone`) с
  опциональным паролем, лимитом слотов и логом в файл.

### Движок / сборка

- Сборки C++20 и x64.
- vcpkg для сторонних зависимостей (`enet`, `lua`, `sdl2`, …).
- Сохранены целевые UWP-сборки.
- GitHub Actions воркфлоу (`build.yml`) для CI-сборок.

### Исправления стабильности

- Несколько исправлений пути запуска для Windows-десктопной сборки (SDK /
  рантайм, загрузка динамических библиотек), чтобы игра запускалась из
  исходников.
- Набор тестов в `src/tests/`, покрывающий сетевой слой целиком.

> Изначально игра выходила только как розничный продукт; **данные игры не
> входят в этот репозиторий**. Оригинальные файлы игры нужно предоставить самому.

## Установка

### Быстрая установка (готовые бинарники)

> [!NOTE]
> Бинарники доступны, только если сборка опубликована в Releases.

### Desktop

1. Скачайте последнюю сборку со [страницы релизов](https://github.com/username-c446/SRR2-Open-Rebuild/releases/latest).
2. Распакуйте содержимое zip-файла в нужное место.
3. Перейдите в распакованную папку и найдите `SRR2.exe`.
4. Можно запускать игру.

### Xbox Series S|X

> [!WARNING]
> Xbox One сейчас не поддерживается и упадёт; Xbox Series S|X работает.

1. Перейдите на [страницу релизов](https://github.com/username-c446/SRR2-Open-Rebuild/releases/latest).
2. Скачайте файл вида `SRR2_UWP_X.X.X.X_x64_XXX.appx`.
3. Откройте портал dev mode на Xbox (https://xbox:11443/ или локальный IP и порт, которые показывает дашборд dev mode).
4. Нажмите «Add» и перетащите загруженный AppX.
5. Готово, должно запуститься.

### Установка для разработки (сборка из исходников)

Для работы с исходниками понадобится:

- Visual Studio 2026
- Поддержка C++ (в установщике Visual Studio выберите `Desktop development with C++` и `Universal Windows Platform development`)
- Поддержка Vcpkg (при выборе `Desktop development with C++` поставьте галочку `Vcpkg package manager` справа)

#### Настройка

> [!NOTE]
> Если вы раньше собирали vcpkg-проекты в Visual Studio, пропустите всё, что после шага 3.

1. Откройте командную строку, перейдите в папку для исходников и выполните `git clone --recurse-submodules https://github.com/username-c446/SRR2-Open-Rebuild`.
2. Затем откройте `SRR2.sln` в Visual Studio.
3. В Visual Studio нажмите `Tools -> Command Line -> Developer Command Prompt`.
4. Откроется окно разработки; введите `cd tools/vcpkg` и затем `./bootstrap-vcpkg.bat`.
5. После этого выполните `./vcpkg integrate install`.

#### Сборка

Если настройка прошла успешно, вы сможете собрать любой проект в решении. При
сборке для UWP не забудьте сменить конфигурацию (например, с `ReleaseWindows`
на `ReleaseUwp`).
