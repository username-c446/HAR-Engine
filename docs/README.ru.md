# HAR-Engine

> Исходной базой послужила игра _The Simpsons: Hit & Run_ — взяты только
> каркас и исходники как отправная точка. Дальше проект развивается как
> **самостоятельный игровой движок**, чьи возможности значительно шире
> скромного функционала оригинала.

Этот репозиторий — движок, собираемый из исходников: C++20 и x64, vcpkg для
сторонних библиотек, кроссплатформенные цели (включая UWP), переиспользуемый
сетевой слой на ENet и собственные инструменты для контента.

> Архитектура сети — в **[SPEC.ru.md](./SPEC.ru.md)**.
> UI/HUD/оверлеи — в **[HUD_AND_OVERLAY_DEV.ru.md](./HUD_AND_OVERLAY_DEV.ru.md)**.

---

## Что это за движок

От основы игры здесь осталось инженерное ядро (загрузка уровней, рендер,
объекты мира, транспорт). Всё поверх строится заново как **модули движка**,
каждый из которых переиспользуем и расширяем:

- **Сетевой слой** (`src/game/netengine/`): клиент-сервер на ENet с
  серверно-авторитетной моделью, версионируемые пакеты, реестр обработчиков,
  пароль/авторизация, валидация движения, релей.
- **Мультиплеер**: host/join, консольные команды и CLI-автостарт
  (`HOSTPORT=`, `JOINIP=`, `HOSTPASS=`, `HOSTSLOTS=`, `JOINPASS=`), удалённые
  сущности с интерполяцией, список игроков, heartbeat/RTT, выделенный
  headless-сервер (`mp_standalone`).
- **Движковые инструменты для контента**: генератор `.p3d`-проектов UI
  (`P3DWriter`), рантайм-интерфейс (Scrooby), кастомный HUD/оверлеи чистым кодом.
- **Моддинг**: серверные скрипты (Lua) с хуками допуска/валидации/выхода.
- **Сборка**: C++20, x64, vcpkg, CI (GitHub Actions).

Суть подхода — **«код без обязательных ассетов»**: движок работает и без
поставляемых данных оригинальной игры, деградируя вместо падения.

---

## Данные

> Данные оригинальной игры (арт, уровни, звук) **не входят** в этот репозиторий
> и не требуются для разработки движка. Для запуска старого контента их нужно
> предоставить отдельно; сам движок собирается и работает с собственным
> контентом и заглушками.

## Сборка

### Для разработки (из исходников)

Нужно:
- Visual Studio (Desktop development with C++) и поддержка UWP цели.
- Vcpkg (галочка `Vcpkg package manager` в установщике).

1. `git clone --recurse-submodules <url>` и откройте `SRR2.sln`.
2. В Developer Command Prompt: `cd tools/vcpkg` → `./bootstrap-vcpkg.bat` → `./vcpkg integrate install`.
3. Соберите нужный проект. Для UWP смените конфигурацию `ReleaseWindows` → `ReleaseUwp`.

Нотация сборки (настроено на этой машине): `MSBuild.exe src/srr2/SRR2.vcxproj
/p:Configuration=DebugWindows /p:Platform=x64 /p:WindowsTargetPlatformVersion=10.0.22621.0`
(проект `sim` целится в отсутствующий SDK 10.0.26100.0, версию переопределяем
в командной строке).

### Тесты

Сборка: `MSBuild.exe src/tests/Tests.vcxproj "/p:Configuration=Debug"
"/p:Platform=x64" /p:WindowsTargetPlatformVersion=10.0.22621.0`
Прогон: `vstest.console.exe src\tests\x64\Debug\Tests.dll`. Ветка «готово»
только при зелёных тестах (сейчас 42/42).

## Происхождение

Исходная кодовая база — модифицированный/пересобранный исходник _The Simpsons:
Hit & Run_, выложенный сообществом (современную пересборку сделал
[**3UR**](https://github.com/3UR); она, в свою очередь, происходит из
архивного/утекшего исходника). Заслуга за базовый каркас принадлежит им.
Данный репозиторий берёт этот каркас как отправную точку и развивает его как
**самостоятельный движок**: всякое дальнейшее расширение (сеть, инструменты,
UI, моддинг) реализуется собственными средствами, без привязки к бренду и
контенту игры. Коммерческое использование ассетов/бренда оригинала запрещено;
движок как код — открытый.
